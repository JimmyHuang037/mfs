# 学生成绩查询系统

## 概述

学生登录后可以查看自己的成绩，包括考试类型选择、成绩总览、成绩明细、分数段直方图、年级排名榜。

## 学校规模

- 40人/班 × 12班 = 480人
- 6门科目：语文、数学、英语、物理、化学、政治
- 学生姓名中文

## 考试类型

| 标识 | 中文名 |
|------|--------|
| monthly1 | 月考1 |
| monthly2 | 月考2 |
| midterm | 期中 |
| final | 期末 |

## 功能点

### 需求1 — 登录 ✅（已有）
- 学号+密码登录
- 学生只能看自己的数据

### 需求2 — 选择考试类型
- [x] 下拉选择考试类型（monthly1 / monthly2 / midterm / final）
- [x] 默认显示该类型最近一次考试
- [x] 显示考试日期

### 需求3 — 成绩总览
- [x] 总分
- [x] 班级排名
- [x] 年级排名
- [x] 等级（A/B/C/D/E）

等级按百分位计算：
| 等级 | 范围 |
|:----:|:----:|
| A | 前 10% |
| B | 10%~40% |
| C | 40%~60% |
| D | 60%~90% |
| E | 后 10% |

### 需求4 — 成绩明细
- [x] 每科分数
- [x] 班级平均分
- [x] 年级平均分
- [x] 表格展示（6科）

### 需求5 — 分数段直方图
- [x] 按总分分段统计人数，以直方图展示
- [x] 高亮当前学生所在段
- [x] 支持按班级或年级维度切换查看
- 分数段：0-99、100-199、200-299、300-399、400-499、500-600

### 需求6 — 单科前三 & 总分年级前十
- [x] 每门科目显示年级前三名（姓名+分数）
- [x] 显示总分年级前十名（排名、姓名、总分）

## 数据库变更

### scores 表（已变更）
| 字段 | 类型 | 说明 |
|------|------|------|
| exam_date | DATE | 新增，考试日期，区分同类型的多次考试 |

### 标准化 type 值
| 旧值 | 新值 |
|------|------|
| term / 月考 / 期中 / Final 等 | monthly1 / monthly2 / midterm / final |

### students 表（已变更）
| 字段 | 类型 | 说明 |
|------|------|------|
| class_id | INT NOT NULL | 已添加，关联 classes 表 |

## API 接口（新增）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/scores/exam-types?student_id=X | 考试类型列表+最近日期 |
| GET | /api/scores/overview?student_id=X&type=Y&exam_date=Z | 成绩总览 |
| GET | /api/scores/details?student_id=X&type=Y&exam_date=Z | 成绩明细 |
| GET | /api/scores/segment-stats?type=Y&exam_date=Z&dimension=class|grade | 分数段统计 |
| GET | /api/scores/top-students?type=Y&exam_date=Z | 年级前十+单科前三 |
