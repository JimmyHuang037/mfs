# 学生端学习建议 — 学习决策引擎

## 痛点

学生在备考时容易盲目跟风，缺乏对自身各科投入产出比的理性判断：

- **痛点A - 偏科陷阱**：提升一门化学，但其余五门都下降，总分和排名反而低了
- **痛点B - 高投入低回报**：上海英语很难，每天学8小时只能涨5-10分，总排名反而倒退。例如小h过去两年英语成绩一直低位，短期突破无效，不应随大流突击英语，而应均衡发力争取总排名靠前
- **痛点C - 吃老本停滞**：认为自己物理有老本，寒假没好好复习，开学冲刺三个月止步不前

共同根因：现有系统只有"单次考试快照"，缺少"纵向趋势分析"。

## 定位

**学习建议生成引擎（Learning Recommendation Engine）**

综合学生近四次考试数据，从成绩趋势、年级百分位、科目权重、提分投入产出比（ROI）、优势学科保护、短板分析、稳定性分析、排名变化等多个维度自动生成个性化学习建议，帮助学生更加科学地分配学习时间。

## 入口

在学生端 `/student/scores` 页面顶部 Tab 切换：
- 📝 **成绩查询**（原有功能）
- 💡 **学习建议**（新增）

使用 `StudentShellComponent` 作为父组件承载 Tab 切换。

## 十维度分析引擎

### 1. 提分投入产出比（ROI）⭐⭐⭐⭐⭐

根据科目类型+当前分数区间判断短期提分潜力：

| 科目 | 低分段（大空间） | 中分段（稳步提升） | 高分段（保持为主） |
|------|----------------|------------------|------------------|
| 语文 | <90 | 90-110 | 110+ |
| 数学 | <90 | 90-120 | 120+ |
| 英语 | <90 | 90-120 | 120+ |
| 物理 | <50 | 50-75 | 75+ |
| 化学 | <50 | 50-75 | 75+ |
| 政治 | <50 | 50-75 | 75+ |

> 注：语数英满分150，物化政原始分满分100

### 2. 主科权重 ⭐⭐⭐⭐⭐

语数英每提升10分对总排名影响更大。当语数英平均百分位 > 小三门最高百分位+15% 时触发权重提示。

### 3. 木桶短板分析 ⭐⭐⭐⭐⭐

- **单科严重短板**：最低百分位与次低差距 > 20% → 优先补齐该科
- **多科普遍偏低**：多科百分位 < 40% → 选最容易突破的一门集中投入

### 4. 综合学习重心建议 ⭐⭐⭐⭐⭐

汇总 ROI + 权重 + 短板，生成一段"📋 本阶段建议"总结文案。前端以加粗+蓝色左边框高亮显示。

### 5. 排名区间分析 ⭐⭐⭐⭐☆

| 排名区间 | 文案 |
|---------|------|
| 前5% | 年级领先，建议保持优势、稳中求进 |
| 前20% | 已具备竞争力，可冲刺更高目标 |
| 20-50% | 基础较稳，仍有明显提升空间 |
| 50-80% | 建议加强基础训练，提高稳定性 |
| 后20% | 建议优先巩固基础知识，逐步建立信心 |

### 6. 波动稳定性 ⭐⭐⭐⭐☆

变异系数(CV) = 标准差/均值：
- CV > 0.25 → "成绩波动较大，提升发挥稳定性比增加练习量更重要"
- CV < 0.08 → "成绩较为稳定，知识掌握扎实"

### 7. 优势科保护 ⭐⭐⭐⭐☆

百分位 ≥ 90%（年级前10%）→ "核心优势科目，避免因过度投入其他科目导致优势缩水"

### 8. 最近一次发挥 ⭐⭐⭐☆☆

对比最近一次与历史均值：
- 偏差 > 满分10% → "发挥明显优于平时，总结成功经验"
- 偏差 < -满分10% → "低于历史平均，不必焦虑，分析失分原因"

### 9. 排名变化幅度 ⭐⭐⭐☆☆

- 提升 > 100名 → "学习策略效果好，继续保持"
- 下降 > 100名 → "认真分析原因，及时调整策略"
- 小幅波动不提醒

### 10. 总排名趋势

连续3次同方向才触发（避免单次波动误判）。

## 建议归并与展示规则

- **同一科目的多条建议自动归并为一条**，用分号连接
- 按科目顺序输出（语数英物化政），再输出通用建议
- **总建议（is_summary=true）前端加粗+蓝色左边框高亮**
- 每条建议带 emoji 图标（⚠️下滑 / 🌟进步 / 💪优势 / ✅稳定 / 💡其他）

## 技术实现

### 后端
- `score_service.py`: `_get_roi_tier()` ROI区间判断
- `score_service.py`: `_generate_advice_text()` 十维度建议生成+归并
- `score_service.py`: `_build_summary()` 综合学习重心建议
- `scores/routes.py`: `/learning-advice` 端点

### 前端
- `StudentLearningAdviceComponent`: ECharts折线+雷达图+建议列表
- `StudentShellComponent`: Tab切换容器
- `main.ts`: `NgxEchartsModule.forRoot({ echarts })` 注册
- 建议列表支持结构化渲染：科目标签+归并文本+总建议加粗
