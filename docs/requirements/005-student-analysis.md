# 老师端学情分析

## 痛点

现有老师端只能看到**班级层面**的统计（班级总分排名、分数段、前三名、同科对比），
无法看到**学生个体**的学习状态。但老师需要知道每个学生属于哪种类型，
以便区别对待：哪些不用管、哪些需要盯一盯、哪些在摆烂。

## 核心模型

```
成绩波动 = 能力值 × 考试难度 + 噪声
```

每个学生有潜在能力值，成绩在不同考试中波动。通过分析 4 次考试（monthly1/monthly2/midterm/final）的纵向数据，可以估算出：

- **能力值**（归一化 0-100）：4 次考试平均分归一化
- **趋势**（斜率）：线性回归方向，正=进步，负=退步
- **波动**（变异系数）：标准差/均值，低=稳定，高=波动大

## 学生分类

基于班级内百分位阈值进行分类：

| 分类 | 条件 | 建议 |
|------|------|------|
| 🏆 **天才型** | 能力值 ≥ p75 且 波动 < 0.15 | 能力突出、成绩稳定，无需额外关注 |
| 📈 **潜力型** | 能力 ≥ p25 且 (趋势>0 或 波动>0.2) | 有提升空间，盯一盯就能上去 — **重点目标** |
| 💪 **上进型** | 趋势 > 0.5 或 能力 ≥ p25 且趋势 > 0.5 | 持续进步中，鼓励为主 |
| 📉 **下滑型** | 能力 ≥ 班级均值 且 趋势 < -0.5 | 能力不错但成绩下滑，需要干预 |
| 😴 **摆烂型** | 能力 < p25 且 趋势 ≤ 0 | 成绩偏低且无改善，需了解原因 |

## 新增功能

### 第4Tab：学情分析

在老师端 `/teacher/scores` 新增第4个 Tab「学情分析」，包含：

#### 1. 概况卡片
- 总人数 + 5 种分类的人数统计
- 点击分类卡片可快速筛选该类学生

#### 2. 四象限散点图
- X 轴：能力值（归一化 0-100）
- Y 轴：趋势（进步/退步）
- 象限分割线将图分为四个区域
- 每个点代表一个学生，颜色区分分类
- 悬浮显示姓名，点击查看成绩轨迹

#### 3. 学生状态列表
- 表格展示：姓名、能力值、趋势、波动、分类、建议
- 按需关注程度排序（high → medium → low）
- 高关注行左侧有橙色边框标识
- 过滤：按班级 + 按分类筛选
- 点击学生行查看成绩轨迹

#### 4. 学生成绩轨迹
- 点击学生后弹出轨迹卡片
- 展示该生 4 次考试的原始分
- 对比班级平均分和年级平均分
- 横向柱状图，直观对比

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/statistics/student-analysis?teacher_id=X` | 学情分析：所有学生能力/趋势/波动/分类 |
| GET | `/api/statistics/student-trajectory?student_id=X&subject=Y` | 单个学生历次考试轨迹(含班级/年级平均) |

## 算法详情

### 归一化
- 语数英原始分 0-150 → 归一化 0-100：`score / 150 * 100`
- 物化政原始分 0-100 → 归一化 0-100：`score * 1`（不变）

### 线性回归
4 个数据点 (x=1,2,3,4 对应 monthly1→final)，计算斜率：
```
slope = (n*Σxy - Σx*Σy) / (n*Σxx - Σx*Σx)
```

### 波动
变异系数 = 标准差 / 均值

### 班级百分位
班级内所有学生的能力值排序，取 p25/p50/p75/mean 作为分类阈值。
