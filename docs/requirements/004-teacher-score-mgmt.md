# 老师端成绩管理与统计分析

## 概述

老师登录后可对自己所教班级进行成绩管理（查看/添加/编辑/删除/导入）和统计分析（班级总分排名、任教科目分数段分布、同科对比）。

## 用户角色

**老师** — 登录后可管理自己任教班级和科目的成绩。

## 功能点

### 页面布局

老师端 `/teacher/scores` 改为带 Tab 标签的单页面：

| Tab | 内容 |
|-----|------|
| 成绩管理 | 班级筛选 + 成绩表格 + 增删改 + xlsx 导入 |
| 班级统计 | 班级考试总分排名柱状图 + 任教科目分数段分布 + 本班单科前三 |
| 同科对比 | 同科老师所教班级平均分横向对比柱状图 |

### Tab 1 — 成绩管理

- [x] **班级筛选**：下拉选择该老师所教的班级（4 个班）
- [x] **成绩表格**：显示选中班级所有学生的成绩
- [x] **添加成绩**：
  - 字段：学号（手动）、科目（手动）、考试类型（手动）、分数（手动）
  - 班级：根据学号自动填充（一个学生只属于一个行政班）
  - 考试日期：后端自动填充 `CURDATE()`，不展示给用户
- [x] **行内编辑**：表格中直接修改科目/类型/分数，回车或失焦保存
- [x] **删除**：已有删除功能
- [x] **xlsx 导入**：
  - 上传 xlsx 文件，表头固定 4 列：学号、科目、类型、分数（不限列顺序）
  - 学号不存在时跳过该行
  - 导入完成后显示成功/失败条数报告

### Tab 2 — 班级统计

- [x] **班级考试统计柱状图**：
  - 选择考试类型（月考1/月考2/期中/期末）
  - X 轴：该老师的 4 个班
  - Y 轴：各班的**总分平均分**
  - 柱子上标注具体分数
  - 显示排名顺序（从高到低排列）
- [x] **分数段分布**：
  - 选择班级 + 考试类型
  - 展示该老师**任教科目**的分数段分布柱状图
  - 分数段：0-59、60-69、70-79、80-89、90-100
- [x] **单科前三**：
  - 选择班级 + 考试类型
  - 表格展示本班 6 个科目各自的前三名（排名、学生姓名、分数）

### Tab 3 — 同科对比

- [x] **同科对比柱状图**：
  - 横向柱状图
  - 每根柱子代表一位同科老师（如语文：张建国、林志文、吴淑敏）
  - 数值为该老师所教班级在该科目的平均分
  - 当前登录老师的柱子高亮显示
  - 柱子上标注具体分数

### 全局约束

- [x] **分数步长 0.5**：xlsx 导入时非 0.5 倍数行跳过（不做前后端强制校验）

## API 接口

### 新增接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/classes/<class_id>/students` | 获取某班所有学生列表 |
| GET | `/api/classes/<class_id>/scores?type=Y&exam_date=Z` | 获取某班某次考试全部成绩 |
| GET | `/api/statistics/class-total-rank?teacher_id=X&type=Y&exam_date=Z` | 班级总分平均分排名 |
| GET | `/api/statistics/subject-segments?class_id=X&teacher_id=Y&type=Z&exam_date=W` | 任教科目分数段分布 |
| GET | `/api/statistics/class-top3?class_id=X&type=Y&exam_date=Z` | 班级各科前三名 |
| GET | `/api/statistics/subject-teacher-compare?teacher_id=X&type=Y&exam_date=Z` | 同科老师班级平均分对比 |
| POST | `/api/scores/import-xlsx` | 上传 xlsx 批量导入成绩 |

### 修改接口

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | `/api/scores/<score_id>` | 修改时后端校验分数为 0.5 步长 |

## 不做（明确排除）

- 老师独立登录页（共用现有登录页）
- 考试日期手动输入（后端自动填充）
- 饼图/折线图等其他图表类型
- 成绩导出功能
- 学生端改动

## 技术约束

- 图表：CSS 柱状图（与学生端风格一致，不引入外部图表库）
- xlsx 解析：后端使用 Pandas 的 `read_excel()` 或 openpyxl
- 文件上传：Flask 原生文件上传
- 分数校验：不做前后端强制校验，仅 xlsx 导入时非 0.5 倍数行跳过
- 前端分 Tab：Angular Material Tab 组件
